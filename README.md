**C++ Technical Repository**

This repository contains 17 C++ programs that I have created for practice and learning. These programs cover basic programming concepts, arrays, strings, mathematical calculations, and simple games.

Programs Included

1. ASCII Value of a Character
Finds and displays the ASCII value of a given character.

2. Array Manipulation
Performs addition, subtraction, and multiplication of arrays, and finds the largest, smallest, and average values.

3. Leap Year Program
Checks whether a given year is a leap year or not.

4. Largest Word in a String
Finds the largest word in a given sentence or string.

5. Next Alphabet in the Alphabet Series
Finds the next alphabet in the English alphabet series, such as A to B or B to C.

6. Quadratic Equation
Calculates the roots of a quadratic equation using its coefficients.

7. Number of Vowels in a String
Counts the number of vowels present in a given string.

8. Reverse a String
Reverses a given string and displays the result.

9. Scientific Calculator
Performs mathematical operations such as power, square root, and trigonometric calculations.

10. Sum of Natural Numbers and Squares of Natural Numbers
Calculates the sum of natural numbers from 1 to n and the sum of their squares.

11. Sorting of a String
Arranges the characters of a string in alphabetical order.

12. Simple Calculator
Performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

13. User ID and Password Program
Checks the entered user ID and password to verify the login details.

14. Vowel or Consonant Checker
Checks whether the entered alphabet is a vowel or a consonant.

15. Casino Game
A simple number-guessing game where the player tries to guess the correct number.

16. CGPA Calculator
Calculates CGPA based on the grades or grade points entered by the user.

17. Rock, Paper, Scissors Game
A simple game where the user plays rock, paper, or scissors against the computer.
